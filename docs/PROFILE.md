## Accounting focus

- Bookkeeping, bank and credit-card reconciliations, and month-end support.
- Property accounting, trust-balance review and intercompany transaction analysis.
- Receivables, payables, cash-flow planning and management reporting.
- Construction cost scenarios and transparent financial modeling.

## How this portfolio is built

Each tool explains its input format, calculation rules, review needs and limitations. Sample datasets are fictional. Tests and measured benchmarks are linked from the repository. The code was developed with AI assistance and is open for review; no independent software audit is claimed.

The hub is a public beta resource library. It does not connect to bank accounts, post accounting entries, file taxes or replace professional judgment. Source files and documentation are available under the repository's MIT license.
