# Changelog

## v0.2.0 — 2026-11-19

- Organized the repository as the APEX Accounting & Finance Hub with task paths, a searchable local landing page, worked examples and twelve CSV templates.
- Added AR/AP aging, intercompany transfer review and trust-balance comparisons in a standalone accounting workbench.
- Expanded the Finance Lab with cost-to-complete scenarios, annual operating projections, DCF sensitivities, editable weekly cash flows and assumption exports.
- Replaced the ledger importer’s growing in-memory ID set with disk-backed SQLite processing, bounded result previews, exact monetary controls and a CLI.
- Added a reproducible one-million-row synthetic benchmark and documented its measured scope.
- Extended automated financial, dashboard, browser-core and repository checks; preserved the original reconciliation rules and examples.
- Added contribution templates, a tool catalog, data schemas and clear current-versus-planned capabilities.

## 0.1.0 — 2026-11-10

- Initial standalone browser tool and fictional demonstration data.
- Conservative one-to-one match suggestions, duplicate flags, amount/date differences, and unresolved candidates.
- Account/currency-separated transaction totals and three CSV exports.
- Engine tests and GitHub Actions workflow.

This is the initial release.
